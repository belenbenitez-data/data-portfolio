\# Nestlé Sales Performance Dashboard | Power BI



\## Project Overview



An interactive Business Intelligence solution developed in Microsoft Power BI to analyze sales performance across multiple markets during 2024 and 2025.



The project integrates transactional sales data and commercial targets to provide insights into revenue performance, product contribution, country-level results, and salesperson performance.



\## Business Objectives



\- Monitor revenue performance against commercial targets.

\- Compare sales results across countries and reporting periods.

\- Identify top-performing products and salespeople.

\- Analyze revenue contribution using Pareto analysis.

\- Evaluate year-over-year performance.

\- Provide actionable insights through interactive reporting.



\## Data Modeling



Designed a relational data model using fact and dimension tables, including:



\- FactSales

\- FactTargets

\- DimProduct

\- DimCountry

\- DimSalesperson

\- DimDate



The model supports analytical reporting through relationships between transactional data, targets, and descriptive dimensions.



\## Key Features



\- Revenue, boxes sold, and transaction KPIs.

\- Target achievement analysis.

\- Country and product performance comparisons.

\- Salesperson contribution analysis.

\- Year-over-year comparisons.

\- Pareto 80/20 analysis.

\- Dynamic Row-Level Security (RLS) based on user access and country permissions.
